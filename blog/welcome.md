title: Welcome to This Template

This is an example blog post. It's written in plain Markdown and gets
rendered to HTML by `pandoc` using the `blog/template.html` layout.

## How it works

Every `.md` file in `blog/` is compiled to a matching `.html` file when you
run `make`. If the file starts with a `title:` line, that becomes the page
title — otherwise the title is derived from the filename.
